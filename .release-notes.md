## What changed

- **Link Column keeps the page size the view already has.** In 0.1.0 its
  *Page size* property defaulted to 25, and because a default on an optional
  property is handed to the control whether or not anyone set it, every
  installed Link Column asked for 25 rows — replacing a user's own *Rows per
  page* on a main grid and the maker's setting on a subgrid. Left empty, it now
  uses the size the host is already retrieving with and asks for nothing. Set,
  it still overrides.
- A view now loads once when Link Column mounts, not twice: the second load
  was the one the control asked for itself.

## Fixed

- **Changing the page size goes back to page 1.** Recutting the rows while on
  page 3 asked for a page 3 that no longer held anything, which looked like an
  empty view.

Link Field is unchanged.

## What you must do

If a Link Column view relied on showing exactly 25 rows, set **Page size** to
25 on it. Otherwise nothing: an empty *Page size* now follows the view's own
setting.
